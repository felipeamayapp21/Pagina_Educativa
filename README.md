## 🎯 Sobre el proyecto

**Página Educativa 2026** es una plataforma web desarrollada como proyecto académico para la asignatura **Desarrollo de Contenidos Digitales y Multimediales** (Grupo B193 — 2026) en las **Unidades Tecnológicas de Santander (UTS)**.

El objetivo fue diseñar e implementar una interfaz moderna que facilite el acceso a contenido educativo, aplicando buenas prácticas de desarrollo web, diseño responsive y herramientas de inteligencia artificial como apoyo en el proceso creativo y técnico.

## ⚙️ Cómo ejecutarlo localmente

No se requiere instalación de dependencias. Solo sigue estos pasos:

```bash
# 1. Clona el repositorio
git clone https://github.com/felipeamayapp21/pagina-educativa.git

# 2. Entra a la carpeta del proyecto
cd pagina-educativa

# 3. Abre el archivo principal en tu navegador
# Opción A — Doble clic en index.html
# Opción B — Con VS Code y la extensión Live Server:
code .
# Luego clic derecho en index.html → "Open with Live Server"
```

## 🤖 Herramientas de IA utilizadas

Este proyecto integró inteligencia artificial como apoyo en diferentes etapas del desarrollo. Todas las decisiones finales fueron tomadas y validadas por los autores.

| Herramienta | Uso en el proyecto |
|---|---|
| **Claude** | Diseño de interfaz, experiencia de usuario (UI/UX) y estructura del código |
| **ChatGPT** | Asistencia técnica, creación y optimización de prompts |
| **Gemini** | Generación de recursos gráficos e imágenes |
| **Tyles** | Optimización de prompts y eliminación de muletillas |
| **OpenCode** | Apoyo en la lógica e implementación del código |

> 📌 El uso de estas herramientas fue transparente y declarado como parte de las buenas prácticas académicas del proyecto.
